METE'NİN KEŞİF ADASI — GITHUB SÜRÜMÜ

İÇERİK
23 oyun/etkinlik kategorisi ve Dünya Bayrakları bölümü.
249 ISO 3166-1 ülke/bölge bayrağı, Türkçe ve İngilizce ülke adları.
Kazı kazan, ülke adı-bayrak eşleştirme, bayrak bilgi yarışması, aranabilir bayrak albümü.
Türkçe ve İngilizce seslendirme: cihazın konuşma sentezi (speechSynthesis) kullanılır.
Seslerin kalitesi ve dil desteği cihaz/tarayıcıya bağlıdır.
Bayraklar işletim sisteminin renkli bayrak emoji desteğiyle gösterilir.
Puanlar tarayıcı localStorage alanında tutulur.

GITHUB PAGES KURULUMU
1. ZIP dosyasını açın.
2. mete-kesif-adasi-final klasörünün İÇİNDEKİ index.html ve assets klasörünü
   GitHub deponuzun ana dizinine yükleyin.
3. Repository > Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Oluşan GitHub Pages adresini iPhone Safari'de açın.
5. Safari Paylaş > Ana Ekrana Ekle ile uygulama kısayolu oluşturabilirsiniz.

NOTLAR
Bu oyun HTML/CSS/JavaScript ile çalışan, 3D görünümlü 2D prototiptir.
Gösterilen örnek tasarımın tüm sahneleri birebir oynanabilir 3D modellere dönüşmüş değildir.
Oyun içeriği küçük çocuklarda yetişkin gözetimiyle kullanılmalıdır.
