# Mete Öğreniyor

Mete için oynayarak Türkçe ve İngilizce öğrenme uygulaması (2-7 yaş).

- 6 konu: Hayvanlar, Renkler, Sayılar, Yiyecekler, Aile, Taşıtlar
- 4 oyun: Doğru olanı bul, Eşleştir, Dinle ve bul, Hafıza
- Dil: Türkçe, İngilizce veya ikisi birden (sesli okuma)
- Yıldız ödülleri, ebeveyn paneli (toplama sorusuyla kilitli)
- İnternetsiz çalışır (ilk açılıştan sonra)
