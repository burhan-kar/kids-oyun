# Minik Kaşif Pro V2

React + Phaser ile geliştirilmiş 2–4 yaş çocuklar için özgün eğitici oyun platformu.

## Bu sürümde çalışan oyunlar

1. Hayvan Kulesi
2. İtfaiye
3. Kurtarma
4. Çiftlik
5. Yapboz
6. Boyama
7. Hayvan Sesleri
8. Sayı Treni

## GitHub Pages Kurulum

Bu proje artık tek index.html değildir. Klasör yapısının tamamı GitHub'a yüklenmelidir.

### Yükleme

1. ZIP dosyasını açın.
2. İçindeki bütün dosya ve klasörleri `kids-oyun` deposuna yükleyin.
3. Commit changes yapın.
4. Repository → Settings → Pages bölümüne gidin.
5. Source alanında `GitHub Actions` seçin.
6. Actions sekmesinden `Deploy Minik Kasif Pro` işleminin yeşil tik olmasını bekleyin.

Adres:

https://burhan-kar.github.io/kids-oyun/

## Yerelde Çalıştırma

```bash
npm install
npm run dev
```

## Not

Projede emoji tabanlı prototip görseller kullanılmıştır. İleride profesyonel SVG/PNG oyun assetleri ile değiştirilebilir.
